LisaHost 现在的香港线路基本可以分成三个思路。

**CMI/CU2/CN2 精品网络**更偏向大陆直连。当前公开产品包含 30Mbps、50Mbps 等配置，部分方案还有不限流量版本；它的定位是低延迟、三网优化、香港节点中转和建站。换句话说，买它主要是在买网络路径，而不是住宅 IP。

因此，判断方法其实很简单：

你需要**大陆访问低延迟**，先看 CMI/CU2/CN2。

你需要**香港住宅 IP 属性**，再看 HGC 和 iCable。

你已经确定需要住宅 IP，而且同时比较在意**带宽和流量额度**，iCable 的配置梯度会更好理解。

这并不是说某一条线路在所有场景都更强，而是它们解决的问题不同。
